Market maker: adjust & skew logic

Review of the current C++ implementation in MakeMarketStrategy.cpp / MakeMarketStrategy.h. Generated for handoff — skew math, side gating, and config knobs.

Summary
  • Skew shifts raw bid/ask around adjusted_theo = theo_midpoint + basis using skew_tick_units = floor(NetPo / adjust_position) × adjust_ticks when |NetPo| < max_position; skew_price = skew_tick_units × quote_tick.
  • Side visibility (shouldQuoteSide) uses position vs max only — no order size or resting remainder in the gate.
  • Spreads: base bid/ask spread ticks + resting depth + optional fill extras; then tick-grid finalize.

1. Inventory skew (raw bid / ask)

Implemented in computeInventorySkewedRawBidAsk and mirrored in runFullMmQuoteCycle before finalizeMmPairOnTickGrid.

2. Side gating — shouldQuoteSide

Uses rounded net position and max_position as a cap magnitude. BUY side shown; SELL is symmetric (long inventory still allows ask).

flowchart TD N[net_ll = llround net position] M[max_ll = max 1, max_position] N --> BUY{"Side == BUY ?"} BUY -->|yes| B1{"net_ll < 0 ?"} B1 -->|yes| QB[want_bid = true] B1 -->|no| B2{"net_ll < max_ll ?"} B2 -->|yes| QB B2 -->|no| NB[want_bid = false] BUY -->|no SELL| S1{"net_ll > 0 ?"} S1 -->|yes| QA[want_ask = true] S1 -->|no| S2{"|net_ll| < max_ll ?"} S2 -->|yes| QA S2 -->|no| NA[want_ask = false] end

3. runFullMmQuoteCycle — high level

After sync: shouldQuoteSide → optional cancel path → build spreads → skew raw prices → grid finalize → quantities use same step-rounded size per active leg.

flowchart LR A[syncInventoryFromExchangePortfolio] --> B[shouldQuoteSide BUY/SELL] B --> C{cancel strategy} C --> D[spread ticks + basis + quote_tick] D --> E[skew raw bid/ask] E --> F[finalizeMmPairOnTickGrid] F --> G[qty_bid / qty_ask from want_* and leg_sz] end

4. Config keys (relevant)

  • market_maker.adjust_position — divisor inside floor(NetPo / adjust_position).
  • market_maker.adjust_ticks — multiplier on that floor for skew tick units (min 1).
  • market_maker.max_position — bounds skew (when |NetPo| ≥ max, skew units = 0) and gates sides in shouldQuoteSide.
